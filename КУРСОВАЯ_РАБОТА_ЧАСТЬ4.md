## 6. ВЫВОДЫ

### 6.1. Результаты работы

В ходе выполнения курсовой работы была разработана программная система **"Книжный магазин"**, которая полностью соответствует заданию (Вариант 13) и реализует все требуемые функции.

**Реализованные обязательные функции:**

✅ **Управление каталогом книг**
- Добавление книг с полной информацией (автор, название, издательство, год, цена)
- Редактирование информации о книгах
- Удаление книг из каталога
- Учет количества книг в наличии
- Поиск книг по различным критериям
- Сортировка книг (6 вариантов)

✅ **Управление покупателями**
- Регистрация покупателей с контактными данными
- Редактирование информации о покупателях
- Удаление покупателей
- Просмотр истории заказов покупателя
- Валидация email адресов

✅ **Оформление заказов**
- Создание заказов с выбором покупателя и книги
- Автоматическая проверка наличия книги
- Управление статусами заказов (CREATED, WAITING, AVAILABLE, COMPLETED, CANCELLED)
- Автоматическое уменьшение количества при завершении заказа
- История всех заказов

✅ **Автоматическая база ожидания**
- Автоматическое добавление покупателя в базу при отсутствии книги
- Автоматическое уведомление покупателей при поступлении книги
- Автоматическое изменение статусов заказов (WAITING → AVAILABLE)
- Просмотр базы ожидания с группировкой по книгам
- Очистка уведомленных записей

✅ **Сохранение данных**
- Автоматическое сохранение всех изменений в JSON файл
- Автоматическое резервное копирование при каждом сохранении
- Восстановление данных при следующем запуске
- Хранение в формате JSON для читаемости

**Дополнительные функции (превышающие требования):**

✅ **Статистика и аналитика**
- Общая статистика по всем разделам
- Статистика каталога (наличие, стоимость, средние цены)
- Статистика заказов с распределением по статусам
- Топ-5 популярных книг с визуализацией
- График заказов по месяцам

✅ **Система ролей**
- Две роли: Администратор и Покупатель
- Гибкое управление доступом к функциям
- Визуальное переключение между ролями
- Ограничение функций для покупателей

✅ **Расширенный функционал**
- Поиск в реальном времени по всем разделам
- Множественные варианты сортировки
- Фильтрация данных (статусы, наличие, покупатели)
- Валидация всех вводимых данных
- Информативные сообщения об ошибках

✅ **Современный пользовательский интерфейс**
- Material Design компоненты
- Интуитивная навигация с боковой панелью
- Цветовые индикаторы статусов
- Карточки для отображения данных
- Диалоговые окна для всех операций
- Иконки для визуальной идентификации

**Технические характеристики системы:**

- **Язык программирования:** Kotlin 1.9.20
- **UI Framework:** Jetpack Compose Desktop 1.5.10
- **Архитектура:** Трехслойная (Presentation - Business Logic - Data)
- **Паттерны:** Repository Pattern, Singleton, Observer
- **Хранение данных:** JSON (kotlinx.serialization)
- **Количество строк кода:** ~3000+ (с комментариями)
- **Файлов исходного кода:** 18 (модели, UI, управление данными)

**Качество реализации:**

- ✅ Код хорошо структурирован и документирован
- ✅ Комментарии KDoc на русском языке
- ✅ Следование best practices Kotlin
- ✅ Отсутствие критических ошибок
- ✅ Стабильная работа без сбоев
- ✅ Корректная обработка всех пользовательских действий

```kotlin
@Serializable
data class Book(
    val id: Int,
    var author: String,
    var title: String,
    var publisher: String,
    var publicationYear: Int,
    var price: Double,
    var quantity: Int = 0
) {

     * Проверить доступность книги
     */
    fun isAvailable(): Boolean = quantity > 0
    
    /**
     * Уменьшить количество книг при продаже
     */
    fun decreaseQuantity(count: Int = 1): Boolean {
        return if (quantity >= count) {
            quantity -= count
            true
        } else {
            false
        }
    }
    
    /**
     * Увеличить количество книг при поступлении
     */
    fun increaseQuantity(count: Int = 1) {
        require(count > 0) { "Количество должно быть положительным" }
        quantity += count
    }
}
```

```kotlin
@Serializable
enum class OrderStatus {
    CREATED,      // Создан
    WAITING,      // В ожидании (книга отсутствует)
    AVAILABLE,    // Доступна (книга поступила)
    COMPLETED,    // Завершен
    CANCELLED     // Отменен
}

@Serializable
data class Order(
    val id: Int,
    val customerId: Int,
    val bookId: Int,
    val creationDate: Long = System.currentTimeMillis(),
    var status: OrderStatus = OrderStatus.CREATED,
    var quantity: Int = 1,
    var lastUpdateDate: Long = System.currentTimeMillis()
) {
    /**
     * Оформить заказ
     */
    fun placeOrder(bookAvailable: Boolean): OrderStatus {
        status = if (bookAvailable) {
            OrderStatus.COMPLETED
        } else {
            OrderStatus.WAITING
        }
        lastUpdateDate = System.currentTimeMillis()
        return status
    }
    
    /**
     * Пометить книгу как доступную
     */
    fun markAsAvailable() {
        if (status == OrderStatus.WAITING) {
            updateStatus(OrderStatus.AVAILABLE)
        }
    }
}
```

```kotlin
/**
 * Обновить количество книги в каталоге
 */
fun updateBookQuantity(bookId: Int, quantity: Int): Boolean {
    val result = appData.catalog.updateCatalog(bookId, quantity)
    if (result) {
        // Проверяем базу ожидания при поступлении книги
        val book = appData.catalog.getBookById(bookId)
        book?.let { checkWaitingListForBook(it) }
        save()
    }
    return result
}

/**
 * Проверить базу ожидания для конкретной книги
 * Уведомляет покупателей и обновляет заказы
 */
private fun checkWaitingListForBook(book: Book) {
    if (!book.isAvailable()) return
    
    // Уведомляем покупателей из базы ожидания
    val notifiedCustomers = appData.waitingList.notifyCustomers(
        book, 
        appData.customers
    )
    
    if (notifiedCustomers.isNotEmpty()) {
        println("✓ Уведомлено покупателей: ${notifiedCustomers.size}")
        
        // Обновляем статусы заказов
        appData.orders
            .filter { it.bookId == book.id && it.status == OrderStatus.WAITING }
            .forEach { it.markAsAvailable() }
    }
}
```
