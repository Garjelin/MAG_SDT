# ПРОДОЛЖЕНИЕ КУРСОВОЙ РАБОТЫ (Часть 2)

## 5.4. Работа с каталогом книг

### 5.4.1. Просмотр каталога

При открытии раздела "Каталог" отображается список всех книг в виде карточек.

```
[СКРИНШОТ: Экран каталога книг с несколькими книгами]

Показать:
- Карточки книг с информацией
- Индикаторы наличия (зеленый "В наличии" / красный "Нет в наличии")
- Оранжевые бейджи с количеством ожидающих
- Панель поиска и фильтров вверху
- Кнопка "+" для добавления книги (для администратора)
```

**Элементы карточки книги:**

1. **Название** (крупный шрифт)
2. **Автор** (под названием)
3. **Издательство и год** (мелким шрифтом)
4. **Цена** (крупно, справа)
5. **Количество** (под ценой)
6. **Индикатор наличия:**
   - 🟢 Зеленый "В наличии" (quantity > 0)
   - 🔴 Красный "Нет в наличии" (quantity = 0)
7. **Бейдж ожидающих** (если есть): 🟠 "Ожидают: N"
8. **Кнопки управления** (только для администратора):
   - ✏️ Редактировать
   - 🗑️ Удалить
   - 📦 Обновить количество

**Панель управления каталогом:**

```
┌─────────────────────────────────────────────────────────────┐
│  🔍 Поиск:  [_____________________]                         │
│                                                              │
│  Сортировка: [По названию ▼]    ☑ Только в наличии         │
└─────────────────────────────────────────────────────────────┘

Варианты сортировки:
• По названию (А→Я)
• По автору (А→Я)
• По году издания (новые → старые)
• По году издания (старые → новые)
• По цене (возрастание)
• По цене (убывание)
```

**Статистика каталога** (вверху экрана):

```
┌──────────────┬──────────────┬──────────────┬──────────────┐
│ Всего книг   │ В наличии    │ Экземпляров  │ Общая стоим. │
│     12       │      10      │      95      │   6 240 ₽    │
└──────────────┴──────────────┴──────────────┴──────────────┘
```

### 5.4.2. Добавление книги

Доступно только администратору. Кнопка "+" в правом нижнем углу экрана.

```
[СКРИНШОТ: Диалог добавления книги]

Показать:
- Поля ввода для всех параметров книги
- Валидацию (красные границы при ошибке)
- Кнопки "Отмена" и "Добавить"
```

**Форма добавления книги:**

```
┌─────────────────────────────────────────────────────────┐
│  ➕ Добавить книгу                                       │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  Автор *                                                 │
│  [_________________________]                             │
│                                                          │
│  Название *                                              │
│  [_________________________]                             │
│                                                          │
│  Издательство *                                          │
│  [_________________________]                             │
│                                                          │
│  Год издания * (1000-2100)                               │
│  [_________________________]                             │
│                                                          │
│  Цена (руб.) *                                           │
│  [_________________________]                             │
│                                                          │
│  Количество *                                            │
│  [_________________________]                             │
│                                                          │
│  * - обязательные поля                                   │
│                                                          │
│  [Отмена]                              [Добавить книгу]  │
└─────────────────────────────────────────────────────────┘
```

**Валидация полей:**

| Поле | Правила | Сообщение об ошибке |
|------|---------|---------------------|
| Автор | Не пустое | "Введите автора" |
| Название | Не пустое | "Введите название" |
| Издательство | Не пустое | "Введите издательство" |
| Год | 1000-2100 | "Год должен быть от 1000 до 2100" |
| Цена | > 0 | "Цена должна быть положительной" |
| Количество | ≥ 0 | "Количество не может быть отрицательным" |

**Логика после добавления:**

1. Книга добавляется в каталог с уникальным ID
2. Если quantity > 0 - автоматически проверяется база ожидания
3. Если есть ожидающие покупатели:
   - Они получают уведомления
   - Статусы их заказов меняются на "Доступна"
   - Выводится сообщение: "Уведомлено покупателей: N"
4. Экран каталога обновляется автоматически

### 5.4.3. Редактирование книги

Кнопка ✏️ на карточке книги (только для администратора).

```
[СКРИНШОТ: Диалог редактирования книги]

Показать:
- Предзаполненные поля текущими значениями
- Те же правила валидации
- Кнопки "Отмена" и "Сохранить"
```

**Форма идентична форме добавления**, но:
- Поля предзаполнены текущими значениями
- Заголовок: "✏️ Редактировать книгу"
- Кнопка: "Сохранить изменения"

**Особенности:**
- ID книги не изменяется
- При увеличении количества - проверяется база ожидания
- История заказов сохраняется

### 5.4.4. Обновление количества книги

Специальная кнопка 📦 "Обновить количество" (только для администратора).

```
[СКРИНШОТ: Диалог обновления количества]

Показать:
- Название книги
- Текущее количество
- Поле ввода нового количества
- Предпросмотр изменения
```

**Диалог обновления:**

```
┌─────────────────────────────────────────────────────────┐
│  📦 Обновить количество                                  │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  Книга: "Война и мир (4 тома)"                           │
│  Автор: Лев Толстой                                      │
│                                                          │
│  Текущее количество: 8 шт.                               │
│                                                          │
│  Добавить количество:                                    │
│  [_________] шт.                                         │
│                                                          │
│  ────────────────────────────────────────────            │
│  Новое количество: 8 + 5 = 13 шт.                        │
│  ────────────────────────────────────────────            │
│                                                          │
│  ⓘ Если есть покупатели в базе ожидания,                │
│     они будут автоматически уведомлены                   │
│                                                          │

└─────────────────────────────────────────────────────────┘
```

**Автоматические действия после обновления:**

1. Количество увеличивается
2. Проверяется база ожидания для этой книги
3. Все ожидающие покупатели получают уведомления
4. Заказы со статусом "WAITING" меняются на "AVAILABLE"
5. Показывается сообщение:

```
✅ Успешно!

Количество обновлено: 8 → 13 шт.
Уведомлено покупателей: 2

• Сидоров П.А. - "Преступление и наказание"
• Смирнов А.В. - "Преступление и наказание"
```

### 5.4.6. Поиск книг

Поле поиска вверху экрана работает в режиме реального времени.

**Поиск выполняется по полям:**
- Автор (частичное совпадение, регистронезависимо)
- Название (частичное совпадение)
- Издательство (частичное совпадение)
- Год издания (точное совпадение)

**Примеры поиска:**

```
Ввод: "пушкин"
Результат: Александр Пушкин - "Евгений Онегин"

Ввод: "война"
Результат: Лев Толстой - "Война и мир (4 тома)"

Ввод: "2020"
Результат: Все книги, изданные в 2020 году

Ввод: "АСТ"
Результат: Все книги издательства АСТ
```

**Индикатор результатов:**

```
Найдено книг: 3 из 12
```

Если ничего не найдено:

```
[Пустой экран с сообщением]

🔍 Ничего не найдено

Попробуйте изменить запрос или очистить фильтры
```

### 5.4.7. Фильтрация и сортировка

**Чекбокс "Только в наличии":**
- Включен: показываются только книги с quantity > 0
- Выключен: показываются все книги

**Сортировка (6 вариантов):**

1. **По названию (А→Я)**
   - Алфавитный порядок названий
   - По умолчанию

2. **По автору (А→Я)**
   - Алфавитный порядок фамилий авторов
   - Группирует книги одного автора

3. **По году издания (новые → старые)**
   - Сначала 2022, потом 2021, 2020...
   - Для поиска новинок

4. **По году издания (старые → новые)**
   - Сначала старые издания
   - Для антикварных книг

5. **По цене (возрастание)**
   - От самых дешевых к дорогим
   - Для экономных покупателей

6. **По цене (убывание)**
   - От самых дорогих к дешевым
   - Для просмотра коллекционных изданий

**Комбинирование:**
Поиск, фильтр и сортировка работают вместе:

```
Поиск: "толстой"
Фильтр: ☑ Только в наличии
Сортировка: По цене (возрастание)

Результат: Книги Толстого в наличии, от дешевых к дорогим
```

### 5.5.2. Добавление покупателя

Кнопка "+" в правом нижнем углу.

```
[СКРИНШОТ: Диалог добавления покупателя]

Показать:
- Поля ввода (ФИО, Email, Телефон)
- Валидацию email
- Кнопки "Отмена" и "Добавить"
```

**Форма добавления:**

```
┌─────────────────────────────────────────────────────────┐
│  ➕ Добавить покупателя                                  │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  Имя (ФИО) *                                             │
│  [_________________________]                             │
│                                                          │
│  Email *                                                 │
│  [_________________________]                             │
│                                                          │
│  Телефон                                                 │
│  [_________________________]                             │
│  Формат: +7 (XXX) XXX-XX-XX                              │
│                                                          │
│  * - обязательные поля                                   │
│                                                          │
│  [Отмена]                         [Добавить покупателя]  │
└─────────────────────────────────────────────────────────┘
```

**Валидация:**

| Поле | Правила | Сообщение |
|------|---------|-----------|
| Имя | Не пустое, мин. 2 символа | "Введите имя (мин. 2 символа)" |
| Email | Формат email (regex) | "Введите корректный email" |
| Телефон | Опционально, формат | "Проверьте формат телефона" |

**Regex для email:**
```
^[A-Za-z0-9+_.-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$
```

**После добавления:**
- Покупатель получает уникальный ID
- Записывается дата регистрации (текущая)
- Список покупателей обновляется
- Выводится сообщение: "✅ Покупатель успешно добавлен!"
