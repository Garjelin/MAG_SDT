# 📚 Система управления книжным магазином

Курсовой проект по дисциплине "Технология разработки программного обеспечения"

## 📋 Описание проекта

Настольное приложение для управления книжным магазином, разработанное на Kotlin с использованием Jetpack Compose Desktop. Система предоставляет функционал для управления каталогом книг, обработки заказов, ведения базы покупателей и списка ожидания.

### ✨ Основные возможности

- 📖 **Управление каталогом книг**: добавление, редактирование, удаление и поиск книг
- 👥 **Управление покупателями**: регистрация покупателей, хранение контактных данных
- 🛒 **Обработка заказов**: создание заказов, отслеживание статусов (доступен/в ожидании/завершен/отменен)
- ⏳ **База ожидания**: автоматическое добавление в список ожидания при отсутствии книги
- 📊 **Статистика**: сводная информация о работе магазина
- 👤 **Система ролей**: Администратор (полный доступ) и Покупатель (ограниченный доступ)
- 💾 **Автоматическое сохранение**: все данные сохраняются в формате JSON
- 🔄 **Импорт/Экспорт**: возможность резервного копирования данных

### 🎨 Интерфейс

Приложение имеет современный интуитивно понятный интерфейс с боковой панелью навигации и Material Design компонентами.

## 🚀 Быстрый старт

### Системные требования

- **Java Development Kit (JDK)**: версия 21 или выше
- **Операционная система**: Windows 10/11, macOS 10.14+, или Linux
- **Память**: минимум 4 GB RAM (рекомендуется 8 GB)
- **Место на диске**: 500 MB для приложения

### Установка JDK (если не установлен)

#### Windows:
1. Скачайте JDK 21 с официального сайта: https://www.oracle.com/java/technologies/downloads/
2. Запустите установщик и следуйте инструкциям
3. Проверьте установку: откройте командную строку и выполните `java -version`

#### macOS:
```bash
brew install openjdk@21
```

#### Linux (Ubuntu/Debian):
```bash
sudo apt update
sudo apt install openjdk-21-jdk
```

### Запуск приложения

#### Вариант 1: Запуск из исходного кода (рекомендуется для разработки)

```bash
# Клонировать или распаковать проект
cd MAG_SDT

# Windows
gradlew.bat run

# macOS/Linux
./gradlew run
```

#### Вариант 2: Создание готового приложения

**⭐ РЕКОМЕНДУЕТСЯ: Создание приложения БЕЗ инсталлятора:**
```bash
gradlew.bat createDistributable
```
Готовая папка: `build/compose/binaries/main/app/BookShop/`  
Запуск: `build/compose/binaries/main/app/BookShop/BookShop.exe`

✅ Не требует установки дополнительных инструментов  
✅ Работает сразу  
✅ Включает Java Runtime

**Для Windows (.msi инсталлятор):**
```bash
# ⚠️ ТРЕБУЕТСЯ установка WiX Toolset 3.11+
# См. АЛЬТЕРНАТИВА_MSI.md для подробностей
gradlew.bat packageMsi
```
Готовый файл: `build/compose/binaries/main/msi/BookShop-1.0.0.msi`

**Для macOS (.dmg):**
```bash
./gradlew packageDmg
```

**Для Linux (.deb):**
```bash
./gradlew packageDeb
```

### Демонстрационные данные

При первом запуске приложение **автоматически создаст полный набор демонстрационных данных**:
- 📚 **12 книг** - классическая русская литература
- 👥 **8 покупателей** - с полными контактными данными
- 📖 Книги в наличии и отсутствующие (для демонстрации базы ожидания)

**Данные сохраняются автоматически** в файл `~/.bookshop/data.json`

Для **сброса данных** к демонстрационным:
1. Закройте приложение
2. Удалите папку `.bookshop` в домашнем каталоге
3. Запустите приложение снова - данные будут созданы заново

## 📖 Руководство пользователя

### Первый запуск

1. При первом запуске приложение создаст папку `.bookshop` в домашнем каталоге пользователя
2. Данные будут автоматически сохраняться в файл `data.json`
3. Резервная копия создается автоматически при каждом сохранении

### Роли пользователей

#### 👨‍💼 Администратор
Полный доступ ко всем функциям:
- Управление каталогом книг
- Управление покупателями
- Просмотр и обработка всех заказов
- Доступ к базе ожидания
- Просмотр статистики

#### 👤 Покупатель
Ограниченный доступ:
- Просмотр каталога книг
- Создание заказов
- Просмотр своих заказов

### Основные операции

#### 📚 Работа с каталогом

**Добавление книги:**
1. Откройте раздел "Каталог"
2. Нажмите кнопку "Добавить книгу"
3. Заполните все поля формы (автор, название, издательство, год, цена, количество)
4. Нажмите "Добавить"

**Обновление количества:**
1. Найдите книгу в каталоге
2. Нажмите "Обновить количество"
3. Введите новое количество
4. При добавлении книг автоматически проверяется база ожидания

**Поиск книги:**
- Используйте поле поиска для фильтрации по автору, названию или издательству

#### 👥 Управление покупателями

**Добавление покупателя:**
1. Откройте раздел "Покупатели" (только для администратора)
2. Нажмите "Добавить покупателя"
3. Заполните ФИО, email и телефон
4. Нажмите "Добавить"

**Редактирование:**
- Нажмите кнопку редактирования рядом с покупателем
- Измените данные и сохраните

#### 🛒 Работа с заказами

**Создание заказа:**
1. Откройте раздел "Заказы"
2. Нажмите "Создать заказ"
3. Выберите покупателя и книгу
4. Укажите количество
5. Система автоматически определит статус:
   - **Доступен**: книга есть в наличии
   - **В ожидании**: книги нет, добавлено в базу ожидания

**Обработка заказов:**
- **Завершить**: пометить заказ как выполненный (книги будут списаны со склада)
- **Отменить**: отменить заказ

**Фильтрация:**
- По покупателю
- По статусу (все, активные, завершенные, в ожидании)
- Поиск по ID заказа

#### ⏳ База ожидания

Автоматически ведется система, когда:
- Покупатель заказывает книгу, которой нет в наличии
- При поступлении книги покупатели из базы ожидания автоматически уведомляются
- Статус заказов меняется с "В ожидании" на "Доступен"

#### 📊 Статистика

Раздел показывает:
- Общее количество книг и их стоимость
- Количество покупателей
- Статистику по заказам (всего, активных, завершенных, в ожидании)
- Размер базы ожидания
- Функции импорта/экспорта данных

## 💾 Хранение данных

### Местоположение файлов

**Windows:**
```
C:\Users\<Username>\.bookshop\
├── data.json          # Основной файл данных
├── data.backup.json   # Автоматическая резервная копия
└── data.backup.<timestamp>.json  # Ручные резервные копии
```

**macOS/Linux:**
```
/Users/<Username>/.bookshop/    (macOS)
/home/<username>/.bookshop/     (Linux)
```

### Формат данных

Данные хранятся в JSON формате с следующей структурой:
```json
{
  "catalog": { ... },
  "customers": [ ... ],
  "orders": [ ... ],
  "waitingList": { ... },
  "nextCustomerId": 1,
  "nextOrderId": 1
}
```

### Резервное копирование

- **Автоматическое**: создается при каждом сохранении
- **Ручное**: через раздел "Статистика" → "Создать резервную копию"
- **Экспорт**: сохранение данных в любой файл

## 🐛 Решение проблем

### Приложение не запускается

**Проблема**: Ошибка "Java version"
- **Решение**: Убедитесь, что установлен JDK 21 или выше
- Проверьте: `java -version`

**Проблема**: Ошибка "JAVA_HOME not set"
- **Решение**: Установите переменную окружения JAVA_HOME

### Ошибки при сборке

**Проблема**: Ошибка при создании MSI ("light.exe exited with 311")
- **Причина**: Не установлен WiX Toolset
- **Решение**: Используйте альтернативу:
  ```bash
  gradlew createDistributable
  ```
  Создаст готовое приложение в `build/compose/binaries/main/app/BookShop/`
- **Или установите**: WiX Toolset 3.11+ (см. `АЛЬТЕРНАТИВА_MSI.md`)

**Проблема**: Gradle build failed
- **Решение**: Очистите кэш и пересоберите:
  ```bash
  gradlew clean build
  ```

**Проблема**: Недостаточно памяти
- **Решение**: Увеличьте heap в `gradle.properties`:
  ```properties
  org.gradle.jvmargs=-Xmx2048m
  ```

### Проблемы с данными

**Проблема**: Данные не сохраняются
- **Решение**: Проверьте права доступа к папке `.bookshop`
- Используйте функцию ручного сохранения

**Проблема**: Данные повреждены
- **Решение**: Восстановите из резервной копии `data.backup.json`
