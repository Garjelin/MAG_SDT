# 📖 Краткое руководство пользователя

## Система управления книжным магазином

---

## 🚀 Начало работы

### Первый запуск
1. Запустите приложение (двойным кликом по `.exe` или через `gradlew run`)
2. Приложение автоматически создаст базу данных с примерами
3. По умолчанию вы работаете под ролью **Администратор**

### Переключение ролей
- Нажмите на блок с текущей ролью в левом нижнем углу
- Выберите нужную роль:
  - **👨‍💼 Администратор** - полный доступ ко всем функциям
  - **👤 Покупатель** - просмотр каталога и создание заказов

---

## 📚 Работа с каталогом

### Просмотр книг
- Все книги отображаются в виде карточек
- **Зеленая метка** "В наличии" - книга доступна
- **Красная метка** "Нет в наличии" - книги нет на складе

### Поиск книг
1. Введите текст в поле поиска вверху экрана
2. Поиск работает по: автору, названию, издательству, году

### Сортировка
Доступные варианты:
- По названию (А-Я)
- По автору (А-Я)
- По году (новые → старые / старые → новые)
- По цене (↑ / ↓)

### Фильтры
- ☑️ **Только в наличии** - показать только доступные книги

### Добавление книги (только Администратор)
1. Нажмите кнопку **"+ Добавить книгу"**
2. Заполните поля:
   - Автор
   - Название
   - Издательство
   - Год издания
   - Цена (в рублях)
   - Количество
3. Нажмите **"Добавить"**

### Обновление количества (только Администратор)
1. Найдите нужную книгу в каталоге
2. Нажмите **"📦 Обновить количество"**
3. Введите количество поступивших книг
4. Система автоматически уведомит покупателей из базы ожидания

### Редактирование книги (только Администратор)
1. Нажмите кнопку **"✏️"** на карточке книги
2. Измените нужные поля
3. Нажмите **"Сохранить"**

### Удаление книги (только Администратор)
1. Нажмите кнопку **"🗑️"** на карточке книги
2. Подтвердите удаление

## 👥 Управление покупателями (только Администратор)

### Просмотр покупателей
- Список всех зарегистрированных покупателей
- Отображается: ID, ФИО, Email, Телефон

### Добавление покупателя
1. Нажмите **"+ Добавить покупателя"**
2. Заполните:
   - ФИО (обязательно)
   - Email (обязательно)
   - Телефон (необязательно)
3. Нажмите **"Добавить"**

### Редактирование покупателя
1. Нажмите **"✏️"** рядом с покупателем
2. Измените данные
3. Нажмите **"Сохранить"**

### Удаление покупателя
1. Нажмите **"🗑️"** рядом с покупателем
2. Подтвердите удаление

### Поиск покупателя
- Введите имя или email в поле поиска

## 🛒 Работа с заказами

### Статусы заказов
- **Создан** - заказ только что создан
- **В ожидании** 🕒 - книги нет в наличии, покупатель в базе ожидания
- **Доступен** ✅ - книга поступила, можно выдать
- **Завершен** ✔️ - заказ выполнен
- **Отменен** ❌ - заказ отменен

### Создание заказа
1. Перейдите в раздел **"Заказы"**
2. Нажмите **"+ Создать заказ"**
3. Выберите покупателя из списка
4. Выберите книгу
5. Укажите количество (по умолчанию 1)
6. Нажмите **"Создать"**

**Что произойдет:**
- Если книга **есть в наличии** → статус "Доступен" или "Завершен"
- Если книги **нет** → статус "В ожидании", покупатель добавлен в базу ожидания

### Просмотр заказов
- **Все заказы** - показать все
- **Активные** - только незавершенные
- **Завершенные** - выполненные заказы
- **В ожидании** - ожидающие поступления

### Фильтрация по покупателю
1. Выберите покупателя из выпадающего списка
2. Нажмите **"Применить фильтр"**

### Завершение заказа (только Администратор)
1. Найдите заказ со статусом "Доступен"
2. Нажмите **"✅ Завершить"**
3. Книги будут списаны со склада

### Отмена заказа
1. Найдите активный заказ
2. Нажмите **"❌ Отменить"**
3. Заказ будет помечен как отменен

## ⏳ База ожидания (только Администратор)

### Что это?
Автоматическая система уведомлений покупателей о поступлении книг.

### Как работает?
1. Покупатель заказывает книгу, которой нет
2. Система автоматически добавляет его в базу ожидания
3. При поступлении книги покупатель получает уведомление
4. Статус заказа меняется на "Доступен"

### Просмотр базы ожидания
- Список покупателей, ожидающих книги
- Отображается: покупатель, книга, дата регистрации, статус уведомления

### Ручное добавление в базу
1. Нажмите **"+ Добавить в ожидание"**
2. Выберите покупателя
3. Выберите книгу
4. Нажмите **"Добавить"**

### Удаление из базы
1. Нажмите **"🗑️"** рядом с записью
2. Подтвердите удаление

### Фильтры
- **Все записи** - все записи
- **Активные** - неуведомленные покупатели
- **Уведомленные** - покупатели, которым пришло уведомление
- **По книге** - фильтр по конкретной книге
- **По покупателю** - фильтр по покупателю

## 📊 Статистика (только Администратор)

### Общая информация
- **Книг в каталоге** - количество различных книг
- **Всего экземпляров** - сумма всех книг на складе
- **Общая стоимость** - стоимость всех книг
- **Покупателей** - зарегистрированных покупателей
- **Всего заказов** - количество всех заказов
- **Активных заказов** - незавершенных заказов
- **Завершенных** - выполненных заказов
- **В ожидании** - ожидающих поступления
- **База ожидания** - записей в базе

### Экспорт данных
1. Нажмите **"📤 Экспортировать"**
2. Выберите место для сохранения
3. Файл сохранится в формате JSON

### Импорт данных
1. Нажмите **"📥 Импортировать"**
2. Выберите JSON файл с данными
3. Данные будут загружены (существующие данные будут заменены!)

### Резервное копирование
1. Нажмите **"💾 Создать резервную копию"**
2. Копия сохранится автоматически с меткой времени

### Загрузка демо-данных
1. Нажмите **"📥 Импортировать"**
2. Выберите файл `demo_data.json` из папки проекта
3. База заполнится примерами книг, покупателей и заказов

## 💾 Сохранение данных

### Автоматическое сохранение
- Все изменения сохраняются **автоматически**
- Данные хранятся в формате JSON
- Создается резервная копия при каждом сохранении

### Где хранятся данные?
**Windows:**
```
C:\Users\<ВашеИмя>\.bookshop\data.json
```

**macOS/Linux:**
```
/Users/<ВашеИмя>/.bookshop/data.json
```

### Резервные копии
- `data.backup.json` - автоматическая резервная копия
- `data.backup.<timestamp>.json` - ручные копии

## 🔧 Решение проблем

### Приложение не запускается
**Решение:**
1. Убедитесь, что установлена Java 21+
2. Проверьте: откройте командную строку и введите `java -version`
3. Если версия меньше 21, установите новую версию

### Данные не сохраняются
**Решение:**
1. Проверьте права доступа к папке `.bookshop`
2. Используйте ручное резервное копирование
3. Экспортируйте данные в другое место

### Ошибка при импорте данных
**Решение:**
1. Проверьте формат файла (должен быть JSON)
2. Убедитесь, что файл не поврежден
3. Используйте файл `demo_data.json` как пример

### Приложение медленно работает
**Решение:**
1. Закройте другие приложения
2. Перезапустите приложение
3. Очистите старые записи из базы ожидания
