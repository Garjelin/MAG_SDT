================================================================================
    ИНФОРМАЦИЯ О КУРСОВОМ ПРОЕКТЕ
================================================================================

НАЗВАНИЕ ПРОЕКТА:
    Система управления книжным магазином (BookShop Management System)

ТИП ПРИЛОЖЕНИЯ:
    Desktop-приложение

ДИСЦИПЛИНА:
    Технология разработки программного обеспечения (ТРПО)

ДАТА СДАЧИ:
    3 ноября 2025

================================================================================
    ТЕХНОЛОГИЧЕСКИЙ СТЕК
================================================================================

Язык программирования:
    - Kotlin 1.9.20

UI Framework:
    - Jetpack Compose Desktop 1.5.10

Целевая платформа:
    - JVM (Java 21)

Система сборки:
    - Gradle 8.x с Kotlin DSL

Хранение данных:
    - JSON файлы (kotlinx.serialization)

Архитектурный паттерн:
    - Repository Pattern
    - MVVM (Model-View-ViewModel)

================================================================================
    СИСТЕМНЫЕ ТРЕБОВАНИЯ
================================================================================

Минимальные требования:
    - JDK 21 или выше
    - Операционная система: Windows 10/11, macOS 10.14+, или Linux
    - Оперативная память: 4 GB (рекомендуется 8 GB)
    - Свободное место на диске: 500 MB

================================================================================
    ИНСТРУКЦИИ ПО ЗАПУСКУ
================================================================================

ВАРИАНТ 1: Запуск из исходного кода (РЕКОМЕНДУЕТСЯ)
-------------------------------------------------------
1. Убедитесь, что установлен JDK 21 или выше
   Проверка: java -version

2. Откройте командную строку в папке проекта

3. Запустите:
   Windows:    gradlew.bat run
   macOS/Linux: ./gradlew run

4. Приложение откроется автоматически

ВАРИАНТ 2: Создание исполняемого файла
-------------------------------------------------------
1. Создайте инсталлятор:
   Windows: gradlew.bat packageMsi
   
2. Файл будет в: build/compose/binaries/main/msi/

3. Запустите инсталлятор BookShop-1.0.0.msi

4. Установите приложение

5. Запустите через меню Пуск или ярлык

ЗАГРУЗКА ДЕМОНСТРАЦИОННЫХ ДАННЫХ
-------------------------------------------------------
1. Запустите приложение
2. Переключитесь на роль "Администратор"
3. Перейдите в раздел "Статистика"
4. Нажмите "Импортировать"
5. Выберите файл demo_data.json
6. База заполнится тестовыми данными

Демо-данные содержат:
- 12 книг (классическая русская литература)
- 8 покупателей
- 8 заказов (разные статусы)
- 2 записи в базе ожидания

================================================================================
    ХРАНЕНИЕ ДАННЫХ
================================================================================

Путь к данным:
    Windows:     C:\Users\<Username>\.bookshop\data.json
    macOS:       /Users/<Username>/.bookshop/data.json
    Linux:       /home/<username>/.bookshop/data.json

Резервные копии:
    - data.backup.json (автоматическая)
    - data.backup.<timestamp>.json (ручные)

Формат:
    JSON (kotlinx.serialization)
